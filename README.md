# python-assignment-part3
# Part 3: File I/O, APIs & Exception Handling

## Project Overview
This repository focuses on **API integration and robust file management**. It handles external data fetching while ensuring the program remains stable through comprehensive exception handling.

## Included Files
* `part3_api_files.py`: The main execution script.
* `python_notes.txt`: A generated text file containing processed data.
* `error_log.txt`: A log file capturing any exceptions or network errors encountered during execution.

## Key Technical Concepts
* **REST API Integration:** Fetching real-time data using the `requests` library.
* **Error Logging:** Implementation of `try-except-finally` blocks to log errors to an external file without crashing the program.
* **File Persistence:** Automating the creation and updating of local text files.
